# Обзор

## Зачем

У CardputerZero 512 МБ памяти. Обычный рабочий стол Raspberry Pi OS (lightdm + labwc для HDMI) и фоновые службы занимают значительную её часть, хотя для работы платы как сервера (ssh, сеть, свои программы) они не нужны.

Server Mode останавливает лишнее и оставляет нужное:

- **Остаётся всегда**: экран CardputerZero и лаунчер APPLaunch, Wi-Fi (NetworkManager/wpa_supplicant), ssh, avahi (имена `.local`), Bluetooth (без него лаунчер постоянно пишет ошибки), звук (pipewire), udisks2.
- **Останавливается** (настраивается): рабочий стол и HDMI, печать, PackageKit, порталы и gvfs, accounts-daemon, NFS.

Экран CardputerZero (SPI-дисплей 320×170, `/dev/fb0`) рисует сам лаунчер напрямую через framebuffer, поэтому рабочий стол ему не нужен.

Ничего не удаляется и не отключается навсегда. Режим сервера живёт до перезагрузки или до обратного переключения. Постоянный эффект дают только опции с перезагрузкой (см. [boot-options.md](boot-options.md)), и у них есть сброс.

## Главный экран

```
Mode: SERVER
Free 297 of 462 MB
Swap 0 MB · desktop stopped
Password: ****
Done: 130 MB -> 184 MB
Tab: settings · hold ESC: exit
```

- Статус обновляется каждые 2 секунды, а во время переключения каждые 200 мс.
- Введите пароль sudo и нажмите Enter: из обычного режима включится режим сервера, из режима сервера вернётся рабочий стол.
- Во время переключения показывается «Enabling server mode… N s». ESC в это время не закрывает программу.
- Результат: «Done: 130 MB -> 184 MB» (MemAvailable до и после), «Wrong password», «Busy…» (уже идёт другое переключение) или код ошибки.

## Экран настроек (Tab)

Три раздела:

1. **Server mode stops (instant)**: какие группы служб останавливать. Переключатель сохраняется сразу в `~/.config/cz-server-mode/stop-groups`, пароль не нужен, действует при следующем включении режима сервера.
2. **Disable at boot (reboot)**: HDMI, камера, cloud-init.
3. **Boot (reboot)**: видеопамять GPU (128/64/32/16 МБ), «Boot into server mode», «Reset all to defaults».

У каждой строки справа значение: `yes` / `no` или `< 64 MB >`. Изменённая, но ещё не применённая строка подсвечивается жёлтым и помечается `*`.

Опции с перезагрузкой применяются по Enter: программа спрашивает пароль, вызывает `advanced.sh apply` только с изменёнными пунктами и через 3 секунды перезагружает плату. При неверном пароле выбранные значения сохраняются, можно ввести пароль снова или отменить (Tab).

Если включено «Boot into server mode» и вы поменяли группы, строка помечается как устаревшая: по Enter загрузочная служба перезапишется с новым набором групп.

## Клавиши

| Экран | Клавиша | Действие |
| --- | --- | --- |
| главный | символы | ввод пароля |
| главный | Enter | переключить режим |
| главный | Backspace / Del | стереть символ / весь пароль |
| главный | Tab | настройки |
| настройки | ↑ ↓ (или `;` `.`) | выбор строки |
| настройки | ← → (или `,` `/`) | изменить значение |
| настройки | Enter | применить опции с перезагрузкой (пароль) |
| настройки | Tab / ESC | назад; в поле пароля Tab отменяет |
| везде | Fn+H | справка |
| главный | удерживать ESC | выход |

Стрелки на клавиатуре CardputerZero находятся на слое Fn (`Fn + ; . , /`). На экране настроек эти клавиши работают и без Fn.

## Сценарий «удалённый сервер»

1. Tab → включить «Boot into server mode», при желании GPU 16 MB, HDMI off, camera off.
2. Enter → пароль → плата перезагрузится сразу в режим сервера: загрузка идёт в `multi-user.target`, рабочий стол не запускается.
3. Чтобы вернуть рабочий стол на время: главный экран → пароль → Enter.
4. Чтобы вернуть всё как было: Tab → «Reset all to defaults» → Enter → пароль.
